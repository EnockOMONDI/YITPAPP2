Registration Process Steps

Step-by-step breakdown of the YITP user registration process, from initial form submission to complete account activation.

Current Status: The registration workflow is fully functional and production-ready with all components working correctly including phone number storage, OTP verification, reliable email delivery, and the new welcome page experience.
1
User Form Submission

User fills out registration form with personal details including phone number

2
Account Creation (Inactive)

Django User object created with is_active=False

3
Profile Creation & Phone Storage

User Profile created via Django signals with phone number properly stored

4
OTP Generation & Email Delivery

6-digit OTP generated with 200-minute expiry and sent via YITP-branded email

5
OTP Verification

User enters OTP code to verify email address

6
Account Activation

User account activated (is_active=True) upon successful OTP verification

7
Welcome Email & Page Redirect

Branded welcome email sent and user redirected to personalized welcome page with onboarding guidance

8
Welcome Page Experience

User sees welcome page with next steps, course enrollment options, and personalized onboarding flow

New Feature: The welcome page provides a smooth onboarding experience, replacing the previous direct login redirect with a more user-friendly introduction to the platform.
