Registration Process Steps

Step-by-step breakdown of the YITP user registration journey, from initial form submission through complete account activation and welcome experience.

Current Status: The registration journey is fully functional and production-ready with comprehensive validation, robust email failure handling, OTP verification system, automatic login, session management, and personalized welcome experience.
1
Form Submission & Validation

User fills out registration form with personal details. System validates for duplicate usernames/emails with message "Username already taken. Please choose a different username." and ensures all required fields are completed.

2
Account Creation (Inactive)

Django User object created with is_active=False to ensure email verification before platform access

3
Profile Creation & Data Storage

User Profile created via Django signals with phone number, personal details, and initial profile completion tracking

4
OTP Generation & Email Delivery

6-digit OTP generated with 200-minute expiry and sent via YITP-branded email using Gmail SMTP. Includes robust email failure handling with fallback mechanisms.

5
Email Failure Handling

If email delivery fails, system automatically activates user account and provides warning message, ensuring users can still access the platform while maintaining security.

6
OTP Verification & Validation

User enters OTP code with validation for correct format, expiry time, and code accuracy. Includes resend functionality for expired codes.

7
Account Activation & Auto-Login

User account activated (is_active=True) upon successful OTP verification with automatic login and session establishment

8
Admin Notification & Welcome Email

Admin notification sent to youthimpactglobal3@gmail.com about new user registration, followed by branded welcome email to user

9
Session Management & Welcome Redirect

Session flag just_completed_otp_verification set for welcome page access control, user redirected to personalized welcome experience

10
Welcome Page & Profile Completion

User sees welcome page with next steps, course enrollment options, profile completion tracking, and guided onboarding flow

Lesson Access & Progression Steps

Step-by-step breakdown of how students access and progress through course content, from initial lesson access to completion and unlocking subsequent content.

Learning Experience: The sequential progression system ensures students follow a structured learning path, building knowledge progressively while maintaining engagement through achievement-based unlocking.
1
Advanced Enrollment Verification

System performs comprehensive enrollment validation using is_accessible_for_user() method, checking active enrollment status and payment verification before granting lesson access

2
Intelligent First Lesson Access

Students can immediately access the first lesson using is_first_lesson_in_course() validation, which automatically identifies the first lesson across all course modules without prerequisites

3
Enhanced Content Rendering & Display

Lesson content is rendered with YITP branding, interactive elements, and real-time progress indicators that update automatically as students engage with content

4
Comprehensive Progress Tracking

Advanced progress tracking with mark_started(), time tracking via add_time_spent(), and automatic progress percentage calculations that update enrollment status in real-time

5
Advanced Lesson Completion

Students mark lessons as completed using mark_completed() method, which automatically triggers progress updates, enrollment percentage recalculation, and next lesson unlocking with timestamp tracking

6
Intelligent Sequential Unlocking

Next lesson becomes accessible only after current lesson completion using get_previous_lesson() validation, ensuring proper learning sequence with detailed prerequisite messaging

7
Seamless Cross-Module Progression

Upon module completion, get_next_lesson() automatically identifies and unlocks the first lesson of the next module, maintaining learning momentum across course boundaries

8
Dynamic Visual Status Indicators

Students see real-time visual indicators for lesson status with automatic updates: completed (✓), in-progress (⏳), locked (🔒), or available (📖) based on prerequisite validation

9
Learning Analytics & Streak Tracking

System automatically calculates learning streaks using get_learning_streak(), tracks time spent per lesson, and provides comprehensive analytics for student progress monitoring
