📋 Required Fields

🔧 Optional Fields

  • author: Author name (defaults to "YITP Admin")
  • category: Category name (created automatically if doesn't exist)

  • status: draft, in_review, or published (default: draft)
  • featured: TRUE/FALSE for featured posts
  • trending: TRUE/FALSE for trending posts
  • publication_date: YYYY-MM-DD HH:MM:SS format
