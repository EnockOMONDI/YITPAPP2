# YITP Documentation Hub

## Overview

Welcome to the comprehensive documentation for the Youth Impact Training Platform (YITP) Learning Management System. This documentation covers all aspects of using, administering, and maintaining the platform.

## 🚀 **Platform Overview**

The YITP LMS is built on modern, secure technologies:
- **Django 5.0.14**: Latest framework with enhanced security
- **Django Unfold**: Modern, YITP-branded admin interface
- **CKEditor 5**: Secure, feature-rich content editor
- **PostgreSQL**: Robust database for production
- **Bootstrap 5**: Responsive, mobile-first design
